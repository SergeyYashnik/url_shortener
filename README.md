# URL Shortener Service

REST API сервис для сокращения длинных URL-ссылок и сбора статистики переходов. Построен на базе PHP 8.3 (Laravel 11) и PostgreSQL 17.

## Технологический стек

- Backend: PHP 8.3 (FPM), Laravel 11
- Database: PostgreSQL 17
- Server: Nginx
- Containerization: Docker, Docker Compose
- Documentation: Scramble (OpenAPI 3)

## Быстрый запуск

Для автоматического развертывания проекта выполните команду в корневой директории:


```bash
make init
```


Команда автоматически выполняет следующие шаги:

- Создает локальный файл конфигурации .env из шаблона .env.example.
- Собирает и запускает Docker-контейнеры в фоновом режиме.
- Устанавливает необходимые зависимости Composer.
- Генерирует уникальный ключ шифрования приложения.
- Применяет миграции структуры таблиц и индексов в базу данных PostgreSQL.
- Полностью очищает кэш конфигурации фреймворка.

## Конфигурация портов

Если на вашем хосте заняты стандартные порты, перед запуском команды "make init" вы можете скопировать .env.example в .env вручную и изменить следующие переменные:

- DOCKER_APP_PORT=8080 — внешний порт веб-сервера (по умолчанию доступен как http://localhost:8080).
- DOCKER_DB_PORT=5432 — внешний порт для прямого подключения к PostgreSQL.

Все остальные настройки окружения оптимизированы и готовы к работе.

## API Документация

В проект интегрирован генератор автоматической документации на основе статического анализа кода. После успешного запуска проекта спецификация эндпоинтов, требования к валидации и форматы JSON-ответов доступны в UI-интерфейсе по адресу:

http://localhost:8080/docs/api

## Управление проектом через CLI

- make up — запустить контейнеры
- make down — остановить инфраструктуру
- make restart — перезапустить сервисы
- make migrate — применить новые миграции
- make clear — сбросить кэш конфигурации приложения
